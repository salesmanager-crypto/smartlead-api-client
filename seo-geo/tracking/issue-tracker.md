## General - sitewide template

- [ ] **AS-001 Duplicate, conflicting company schema (Organization) on every page** (P1, All 86 crawled pages)  
  URL: https://www.albertscott.com/  
  What is happening: Applies identically to all 86 crawled content pages (see the full list in seo-geo/config/site-map.md). Verify on the homepage; the same markup is generated by the theme/plugin on every page, so one fix corrects all of them. View source on any page and search for "application/ld+json": there are two separate Organization blocks. Block 1 (added by All in One SEO): @id "https://www.albertscott.com/#organization", description "E-commerce Management", numberOfEmployees 5 to 10. Block 2 (a custom block, present on the same pages): @id "https://www.albertscott.com/#org", types ["Organization","ProfessionalService"], numberOfEmployees 30, with address, phone, email and a service catalog. The two do not share an @id, so search engines and AI answer engines cannot tell they are the same company, and they show two different employee counts and descriptions for the same business.  
  Fix: In WordPress: All in One SEO > Search Appearance > Schema, turn off (or edit) the Organization block it generates so only one Organization/ProfessionalService block remains on the page (the custom one, since it already has the address, phone and service catalog). Set numberOfEmployees to the one true figure and set description to match the homepage meta description exactly. This is a global setting; it does not need to be repeated per page.  
  Ref: R15
